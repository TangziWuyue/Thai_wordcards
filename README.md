# 泰语组合练习

随机组合泰语辅音与元音，按泰文拼写规则拼成一个音节，自己挑声调，然后跟着念出声。

组合出来的音节大多没有实际词义 —— 这是刻意的：不背单词，只练「看到拼写就能读出来」这条肌肉记忆。

## 快速开始

```bash
python3 -m http.server 8901 --directory web
# 然后打开 http://127.0.0.1:8901
```

也可以直接双击 `web/index.html`（页面用的是普通 `<script>`，不需要打包器，直接打开也能跑）。

## 功能

- **随机拼装**：前引元音 → 首辅音（可带辅音簇）→ 后置元音 → 声调符号 → 尾辅音，严格遵守泰文码点顺序。
- **词表勾选**：44 个辅音按中类 / 高类 / 低类分组，18 个元音（含前引元音、后置元音、复合元音）可随意增删；罕用与已废弃字母默认关闭。
- **声调自选**：无音调 + ่ ้ ๊ ๋，点一下即时换，卡片立刻重排。
- **规则检查（可关）**：`๊` / `๋` 只用于中类辅音；短元音开音节不能标声调。关掉后可以随便试。
- **朗读**：走浏览器 Web Speech API，macOS 上直接用系统泰语语音 Kanya（无需联网、无需 key）。
- **快捷键**：空格随机组合，Enter 朗读。
- **选择记忆**：词表与选项存在 localStorage，下次打开还在。

## 自测

```bash
node --test web/
```

覆盖：辅音表完整性与分类数量、泰文码点区间、拼装顺序（前引元音在辅音之前、声调在元音之后尾辅音之前）、元音约束（必带尾辅音 / 不可带尾辅音）、strict 声调规则、随机生成 5000 次的不变量与可复现性。

## 拼写规则与实现要点

- 泰文的前引元音（เ แ โ ใ ไ）在 Unicode 里排在辅音**前面**，但显示在**左半边**，所以拼接顺序固定为
  `前引元音 → 首辅音(+辅音簇) → 后置元音 → 声调符号 → 尾辅音`，顺序写错就会渲染错位或叠字。
- 引擎**不**判断组合是不是真实存在的泰语词，只保证码点顺序合法、不叠字、约束成立。
- 卡片上的拉丁注音是近似转写、**不含声调**，只作提示。
