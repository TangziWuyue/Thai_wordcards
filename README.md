# 泰语组合练习

**版本：beta2**（2026-09-26）

随机组合泰语辅音与元音，按泰文拼写规则拼成一个音节，自己挑声调，然后跟着念出声。元音的名称、英文名、音标、例词都对齐中国教材《基础泰语（1）》的元音表。

> beta2 更新：新增**固定模式**（「随机组合」按钮右半边切换，自己挑辅音/元音拼读，支持单辅音 `กอ` 与单元音 `อา`）；「遵守拼写规则」开关决定固定模式下是否用 `อ` 补位；选项面板按模式自动灰掉不适用项；修掉一批细节问题（载体标注、大字号行高、字块间距、缓存相关的显示问题）。

组合出来的音节大多没有实际词义 —— 这是刻意的：不背单词，只练「看到拼写就能读出来」这条肌肉记忆。

## 辞典

侧栏的「辞典」面板是常用词牌组：一次只摆几个词，点「换一批」接着翻，不用在长列表里翻找。
卡片上如果碰巧拼出真词，会在音节下面标出来（`真词` + 中文释义 + `常用` / `虚词`），
释义就直接来自下面那份词表，没有经过机器翻译。

词库数据（`web/data/dict.js`，约 1.1MB，**打开页面时按需联网加载**，不拖慢首屏）：

| 内容 | 来源 |
| --- | --- |
| 中文释义（5000 余条） | [thai-vocabulary-studio](https://github.com/kinniuroudong-glitch/thai-vocabulary-studio) 的中泰对照词表，B1/B2/C1 三档 |
| 补缺的基础词 | `web/dict/basic-words.json`（人工核对，问候语、颜色、礼貌语气词这类） |
| 罗马注音（Paiboon 体系）、词性 | [Wiktionary](https://kaikki.org/dictionary/Thai/) 抽取的泰语词条 |
| 真词判定用的词头 | [NECTEC LEXiTRON](https://github.com/brianbv/lexitron-data) + 上面的 Wiktionary |

重新生成（需要联网，原始语料缓存在 `web/dict/.cache/`，不入库）：

```bash
node web/dict/build-dict.mjs        # 生成 web/data/dict.js
node web/fonts/build-cjk-subset.mjs # 释义里的新汉字要补进字体子集，必须重跑
```

「常用」= 词表里最基础的那一档（B1，约 2000 条）；「虚词」= 没有实义、只起语法或语气作用
（ครับ ค่ะ นะ และ 这类），标出来是为了让人知道不用去记它的「意思」。

> 中文释义取自中文作者整理并公开的词表，该项目**没有声明开源协议**，自用没问题；
> 若要正式对外发布，建议先联系作者确认，或替换成自有/授权词表。

## 快速开始

```bash
python3 -m http.server 8901 --directory web
# 然后打开 http://127.0.0.1:8901
```

也可以直接双击 `web/index.html`（页面用的是普通 `<script>`，不需要打包器，直接打开也能跑）。

要把页面发给别人（老师 / 同学），打包成一个文件更省事：

```bash
node web/build-standalone.mjs      # 生成 dist/泰语组合练习.html
```

产物把 CSS、JS、字体、辞典数据全部内联进 HTML（约 3.5MB），**零外部引用**——发过去双击就能用，不需要联网、不需要装泰文字体，也不受 `file://` 跨域限制影响，断网也能查词。改动界面后重新跑一次即可（脚本会自检有没有残留外部引用，有就报错退出）。

## 在手机上用

### 方式一：同一 Wi-Fi 直接访问（临时，最快）

```bash
python3 -m http.server 8901 --directory web
# 然后在手机浏览器打开 http://<这台电脑的局域网 IP>:8901/
# 查本机 IP：ipconfig getifaddr en0
```

手机和电脑要在同一个网络（同一个 Wi-Fi，或电脑连着手机热点）。这个地址只在家里/局域网有效，出门就打不开。

### 方式二：部署到 GitHub Pages（正式，随时可用）

部署内容放在 `docs/`（`index.html` 就是打包好的单文件版，`docs/` 是 GitHub Pages 允许的两个目录之一）。**仓库公开后**，在 Settings → Pages 里把 Source 选成 **Deploy from a branch**、分支选 `main`、目录选 `/docs`，就会得到固定链接：

```
https://<用户名>.github.io/Thai_wordcards/
```

只有一个前提：**仓库要公开**（免费版 Pages 不支持私有仓库）。

更新线上内容时重新构建并复制过去：

```bash
node web/build-standalone.mjs
cp "dist/泰语组合练习.html" docs/index.html
cp "dist/使用说明.txt" docs/使用说明.txt
git add docs && git commit -m "更新线上版本" && git push
```

不想公开仓库的话，可以改用 Vercel / Cloudflare Pages / Netlify——它们支持从**私有**仓库部署，但需要各自注册账号。

## 功能

- **随机拼装**：前引元音 → 首辅音（可带辅音簇）→ 元音前段 → 声调符号 → 元音后段 → 尾辅音，严格遵守泰文码点顺序。
- **两种模式**（「随机组合」按钮右半边的 ⇄ 切换）：
  - 随机模式：每次随机出一个音节，适合自测。
  - 固定模式：自己在词表里点一个辅音、一个元音，卡片立刻拼给你看，适合跟读跟练；也可以只点辅音（显示 `กอ` 这类字母本身读法）或只点元音（显示 `อา` 这类单元音写法）。这个自动补出来的 `อ` 由「遵守拼写规则」开关控制：开着才补位，关掉就不补（只显示 `ก` 或 `า`）——用补不补来代替「变淡/加下划线」，因为泰文组合符号会跟着基字的字色走，染色类做法会把符号一起冲淡。
- **词表勾选**：44 个辅音按中类 / 高类 / 低类分组，默认全开（只有 ฃ ฅ 两个废弃字母默认关）；元音按课本的 **สระ 32 รูป** 分组——单元音 18 / 复合元音 6 / 超额元音 8，另列 3 个拼写变体（`ั` `เ-ิ` `เ-็`）。两组各有一键「全选 / 全不选」。不写元音符号的闭音节（`กบ`）没有字形，不放在词表里，由「选项 → 允许无元音符号的闭音节」控制。
- **悬停/长按看卡片**：鼠标停在词表的任何一个字块上（或键盘聚焦）会弹出放大卡片——上面是大号字形，下面是合并在一起的注释：类别、罗马注音、国际音标、长短音、例词（辅音用传统例词，如 `ก ไก่（鸡）`；元音用课本例词）。手机上**长按**字块同样能弹出，长按不会误触发选中；点到别处或滚动会自动收起。
- **元音充当声母**：可开启，让 `ฤ ฤๅ ฦ ฦๅ` 自己成音节（`ฤดู`、`ฤษี` 类型）。
- **复合声母按真实读音处理**：前引辅音（`หมา = ma`、`หรู = ru`、`ใหญ่ = yai`）、假簇（`จริง = jing`、`ทราย = sai`、`ศรี = si`）、真簇（`ปลา = pla`、`ความ = khwam`）都分别处理，卡片上会标出「前引 ห 不发音」「ทร 整体读 s」这类说明。
- **两套注音可选**：罗马注音（`มา = ma`，与《基础泰语（1）》音标列一致）或国际音标 IPA（`มา = maː`，长音用 ː 标出），随时切换，卡片和提示都会跟着变。
- **声调自选**：无音调 + ่ ้ ๊ ๋，点一下即时换，卡片立刻重排。
- **规则检查（可关）**：`๊` / `๋` 只用于中类辅音；`เ-็` 类元音不写声调符号。关掉后可以随便试。
- **选项随模式变化**：固定模式下「允许辅音簇 / 允许尾辅音 / 允许元音充当声母 / 允许无元音符号的闭音节 / 随机后自动朗读」这几项会变灰、点不动（它们只影响随机生成）；字体、音标、外观与「遵守拼写规则」两种模式都能用。
- **字体可选**：标准体（Sarabun，泰国政府文书标准字体）/ 印刷衬线（Noto Serif Thai）。两种都打包进仓库，中文界面字也按用字切好子集放进来，所以**不依赖机器上装了什么字体**，换台电脑字形一样。两套字体在 `@font-face` 里用 `ascent-override` / `descent-override` 强制成同一组度量——它们原本的上伸/下伸差得多（1.068/0.232 对 1.064/0.534），不改的话同样行高下衬线体会整体偏上。
- **暗色模式**：跟随系统 / 浅色 / 深色三选一，同样会记住。
- **自适应排版**：窄屏单列、宽屏自动变两栏（卡片在左、词表在右），窗口变矮时卡片和字号跟着收，横屏手机也不会溢出。
- **朗读**：走浏览器 Web Speech API，用系统自带的泰语语音（Windows 11 的 `Microsoft Niwat Online`、macOS/iPhone 的 `Kanya`），无需联网、无需 key。没装泰语语音时页脚会提示，鼠标停上去能看到各平台的安装路径。
- **快捷键**：空格随机组合，Enter 朗读。
- **选择记忆**：词表与选项存在 localStorage，下次打开还在。

## 拼写规则与实现要点

- 泰文的前引元音（เ แ โ ใ ไ）在 Unicode 里排在辅音**前面**，但显示在**左半边**，所以拼接顺序固定为
  `前引元音 → 首辅音(+辅音簇) → 元音前段 → 声调符号 → 元音后段 → 尾辅音`，顺序写错就会渲染错位或叠字。
- 声调符号的位置在**元音后段之前**：`น้ำ` = น+้+ำ、`โต๊ะ` = โ+ต+๊+ะ、`เปล่า` = เ+ป+ล+่+า、`ชั่ว` = ช+ั+่+ว、`เพื่อน` = เ+พ+ื+่+อ+น。所以元音被拆成「前段 / 后段」两截。
- `ัว` 在带尾辅音时会省掉 `ั`：`ตัว` → `สวย`、`ช่วง`。
- 尾辅音共 37 个字母（只有 ฃ ฅ ผ ฝ ห อ ฮ 不能作尾辅音），按 แม่กก/กด/กบ/กน/กง/กม/เกย/เกอว 归类。
- 复合声母分三类：真簇（`กร กล คร คล ตร ปร ปล พร พล ฟร กว ขว คว`，两个字母都读）、前引辅音（`ห` 打头的 `หง หญ หน หม หย หร หล หว`，`ห` 不发音）、假簇（`จร` / `ศร` 第二个字母不发音，`ทร` 整体读 s）。
- 元音本来就以某个音结尾时，尾辅音不重复写：`ไทย = thai` 而不是 `thaiy`；`ย` 作尾辅音时罗马注音用 `i`（`สาย = sai`），`ว` 用 `o`（`แมว = maeo`）。
- 引擎**不**判断组合是不是真实存在的泰语词，只保证码点顺序合法、不叠字、约束成立。
- 卡片注音有两种方式可选：罗马注音（拉丁字母拼读，不区分长短音，`มา = ma`）与国际音标 IPA（`มา = maː`）。两者都**不含声调**，只作提示；长短音在元音名称里也标了（`สระ อา` 长 / `สระ อะ` 短）。
- 44 个辅音的传统例词（`ก ไก่`、`ข ไข่` …）写在 `rules.js` 的 `CONSONANT_EXAMPLES` 里，测试会检查 44 个字母都有例词与中文释义。
- IPA 用的是简化音位标注：复合元音 `เอีย / เอือ / อัว` 不标长音符号，短形是否带喉塞尾没有区分。

## 没有收进来的东西

- `ฃ` `ฅ`：已废弃，仅保留在词表里供手动开启。
- 单独用 `็` 代替 `ะ` 的写法（`ก็`、`จ็` 这类）没有建模，只有 `เ-็`。
- `อักษรควบไม่แท้` 只收了 `จร` `ศร` `ทร` 三个常见组合，其它（如 `สร`、`ซร`）没收录；`หร` 等前引组合也只能从「辅音簇」里生成，不能单独指定。
- `ฤ ฤๅ ฦ ฦๅ` 既可以直接跟在辅音后面（`กฤ`、`พฤกษ์`），也可以在选项里开启「元音充当声母」让它们自己成音节（`ฤดู`、`ฤษี`）。
- 复合元音 `เ-ือะ`、`ฦ`、`ฦๅ` 课本的例词栏是空的，卡片里也就没有例词。
