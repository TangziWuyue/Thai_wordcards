# 泰语组合练习

随机组合泰语辅音与元音，按泰文拼写规则拼成一个音节，自己挑声调，然后跟着念出声。元音的名称、英文名、音标、例词都对齐中国教材《基础泰语（1）》的元音表。

组合出来的音节大多没有实际词义 —— 这是刻意的：不背单词，只练「看到拼写就能读出来」这条肌肉记忆。

## 快速开始

```bash
python3 -m http.server 8901 --directory web
# 然后打开 http://127.0.0.1:8901
```

也可以直接双击 `web/index.html`（页面用的是普通 `<script>`，不需要打包器，直接打开也能跑）。

## 功能

- **随机拼装**：前引元音 → 首辅音（可带辅音簇）→ 元音前段 → 声调符号 → 元音后段 → 尾辅音，严格遵守泰文码点顺序。
- **词表勾选**：44 个辅音按中类 / 高类 / 低类分组，默认全开（只有 ฃ ฅ 两个废弃字母默认关）；元音按课本的 **สระ 32 รูป** 分组——单元音 18 / 复合元音 6 / 超额元音 8，另列 4 个拼写变体（`ั` `เ-ิ` `เ-็` 无元音符号）。鼠标停在任何元音上都能看到课本的名称、音标和例词。
- **元音充当声母**：可开启，让 `ฤ ฤๅ ฦ ฦๅ` 自己成音节（`ฤดู`、`ฤษี` 类型）。
- **声调自选**：无音调 + ่ ้ ๊ ๋，点一下即时换，卡片立刻重排。
- **规则检查（可关）**：`๊` / `๋` 只用于中类辅音；`เ-็` 类元音不写声调符号。关掉后可以随便试。
- **字体可选**：标准体（Sarabun，泰国政府文书标准字体）/ 印刷衬线（Noto Serif Thai）。两种都打包进仓库，中文界面字也按用字切好子集放进来，所以**不依赖机器上装了什么字体**，换台电脑字形一样。
- **暗色模式**：跟随系统 / 浅色 / 深色三选一，同样会记住。
- **自适应排版**：窄屏单列、宽屏自动变两栏（卡片在左、词表在右），窗口变矮时卡片和字号跟着收，横屏手机也不会溢出。
- **朗读**：走浏览器 Web Speech API，macOS 上直接用系统泰语语音 Kanya（无需联网、无需 key）。
- **快捷键**：空格随机组合，Enter 朗读。
- **选择记忆**：词表与选项存在 localStorage，下次打开还在。

## 目录结构

```
web/index.html        页面结构
web/style.css         样式（极简黑白灰，无阴影）
web/fonts.css         泰文字体的 @font-face
web/fonts-cjk.css     中文字体子集的 @font-face（脚本生成）
web/app.js            界面逻辑：词表、随机、声调切换、朗读
web/rules.js          拼写规则引擎（纯逻辑，无 DOM 依赖）
web/rules.test.mjs    规则引擎自测
web/fonts/            打包的 woff2、授权说明，以及中文字体子集生成脚本
src/thai_wordcards/   Python 脚手架，目前没有实际功能
```

改动了界面文案以后，中文新字要重新切子集（需要联网）：

```bash
node web/fonts/build-cjk-subset.mjs
```

## 自测

```bash
node --test web/
```

覆盖：辅音表完整性与分类数量、课本 18+6+8=32 元音分组、元音名称/英文名/音标/例词与课本逐条比对、泰文码点区间、拼装顺序、元音约束（必带尾辅音 / 不可带尾辅音）、尾辅音表完整性、strict 声调规则、元音充当声母、真实词拼写抽查（น้ำ โต๊ะ เปล่า เพื่อน เสี้ยว สวย ช่วง ตั๋ว ง่าย ครับ ไทย ใหม่ พ่อ ก่อน ฤ ฤๅ …）、随机生成 5000 次的不变量与可复现性。当前 29 项。

## 拼写规则与实现要点

- 泰文的前引元音（เ แ โ ใ ไ）在 Unicode 里排在辅音**前面**，但显示在**左半边**，所以拼接顺序固定为
  `前引元音 → 首辅音(+辅音簇) → 元音前段 → 声调符号 → 元音后段 → 尾辅音`，顺序写错就会渲染错位或叠字。
- 声调符号的位置在**元音后段之前**：`น้ำ` = น+้+ำ、`โต๊ะ` = โ+ต+๊+ะ、`เปล่า` = เ+ป+ล+่+า、`ชั่ว` = ช+ั+่+ว、`เพื่อน` = เ+พ+ื+่+อ+น。所以元音被拆成「前段 / 后段」两截。
- `ัว` 在带尾辅音时会省掉 `ั`：`ตัว` → `สวย`、`ช่วง`。
- 尾辅音共 37 个字母（只有 ฃ ฅ ผ ฝ ห อ ฮ 不能作尾辅音），按 แม่กก/กด/กบ/กน/กง/กม/เกย/เกอว 归类。
- 引擎**不**判断组合是不是真实存在的泰语词，只保证码点顺序合法、不叠字、约束成立。
- 卡片上的拉丁注音用课本「音标」的写法（不区分长短音，`มา = ma`、`มีด = mit`），**不含声调**，只作提示；长短音在元音名称里体现（`สระ อา` 长 / `สระ อะ` 短）。

## 没有收进来的东西

- `ฃ` `ฅ`：已废弃，仅保留在词表里供手动开启。
- 单独用 `็` 代替 `ะ` 的写法（`ก็`、`จ็` 这类）没有建模，只有 `เ-็`。
- `ฤ ฤๅ ฦ ฦๅ` 既可以直接跟在辅音后面（`กฤ`、`พฤกษ์`），也可以在选项里开启「元音充当声母」让它们自己成音节（`ฤดู`、`ฤษี`）。
- 复合元音 `เ-ือะ`、`ฦ`、`ฦๅ` 课本的例词栏是空的，卡片里也就没有例词。
