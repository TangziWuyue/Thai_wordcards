# 泰语组合练习

**版本：3.1.0**（2026-10-01）· 在线使用：<https://tangziwuyue.github.io/Thai_wordcards/>

勾选若干泰语辅音与元音 → 按泰文拼写规则随机拼出一个音节 → 自己挑声调 → 跟着念出声。
元音的名称、英文名、罗马注音、例词都对齐中国教材《基础泰语（1）》的元音表。

组合出来的音节**大多没有实际词义，这是刻意的**：不背单词，只练「看到拼写就能读出来」这条肌肉记忆。
不想看到无意义音节时，把「组合范围」切到 **常用词**，随机出来的每一个都是词表里真实存在的词。

配套还有一个**拼读教学页** <https://tangziwuyue.github.io/Thai_wordcards/tutorial.html>，
把 44 个辅音、32 个元音、尾辅音、声调规则逐条摊开讲，每个字母都配了发音讲解；练习页右上角有入口。

## 功能

- **拼读教学页**（`tutorial.html`，练习页右上角进入）：仿 jyutping.io 教学页的结构，先讲「一个音节 = 声母 + 元音 + 尾音 + 声调」，再分四部分摊开：

  | 部分 | 讲什么 |
  | --- | --- |
  | 辅音 44 | 按中类 / 高类 / 低类分组，每个字母给「名称（ก ไก่）、罗马注音、发音讲解」，借词用字与已废弃字母单独标出 |
  | 元音 32 | 按单元音 18 / 复合元音 6 / 超额元音 8 分组，另列 4 个拼写变体；每个元音写成 `อ + 元音` 的样子，附长短音与例词 |
  | 尾辅音 | 按实际读音的 8 组（-k -t -p -n -ng -m -y -w）讲「中和」，列出每组有哪些字母、哪些字母不能当尾音 |
  | 声调 | 五个声调的调值与念法，加一张「辅音类别 × 有没有写符号 × 音节死活 → 读第几调」的规则表 |

  **发音讲解的口径对齐《基础泰语（1）》的「发音方法」**：先讲舌头/嘴唇怎么摆，再给一个汉语拼音的对照音（课本说没有对应的就直接说没有），辅音用课本的「X 与 o 相拼」写法，并标出「字母名称读第几声调」（中/低类读第一声、高类读第五声）。
  表里的字形、名称、注音、例词全部从 `rules.js` 现取（练习页和教学页永远说同一件事），只有发音讲解是手写文案，放在 `tutorial-data.js`，测试逐条比对。
  教学页也能单独打包成 `dist/泰语教学.html`，跟练习页放在一起可以互相跳转。

- **教学页搜索**（页面顶部的输入框，按 <kbd>/</kbd> 也能聚焦）：输入泰文字母、罗马注音、中文意思、例词、标签（送气 / 短音 / 尾音…）都能查，空格分开的几个词要**全部**命中；上下键选、回车跳，跳到的那一行会闪一下并标出位置。

  匹配是**严格**的：先只看「字形 / 字母名 / 注音 / 标签 / 所在小节」，搜 `ด` 就只出 `ด`，不会因为别的字母的例词里带 `ด`（`ขวด`、`มีด`、`ฤดู`）而把一堆行带出来；第一档没有命中才退到「名称里的例词」（搜 `ขวด` 找得到 `ฃ`），再没有才退到「讲解正文里提到」（搜「送气」这类概念词，顶部会说明一句）。也可以用 `tutorial.html?q=送气` 直接把搜索结果发给别人。

  泰文和拉丁注音**按整词匹配**，不做「词里包含」：搜 `ไ` 只出 สระ ไอ（不会被 ไม้หันอากาศ、ไม้ไต่คู้、ไม่มีรูป 里那个「ไ」带出来），搜 `ต` 只出 ตอ เต่า，搜 `k` 不会把 `kh` 一起带出来。中文因为没有词边界，仍按包含匹配。

  搜索框**也能查词，两个方向都行**：结果里会多出一段「辞典」，点一个词就跳到练习页，把它摆在卡片上看注音和释义。

  | 输入 | 怎么查 | 例子 |
  | --- | --- | --- |
  | 泰文 | 按拼写前缀（常用词优先） | `ไม` → ไม / ไมโครเวฟ / ไม่ … |
  | 中文 | 按释义反查 | `你好` → สวัสดี；`谢谢` → ขอบคุณ；`姐姐` → พี่ / พี่สาว |
  | 英文（≥4 个字母） | 按英文释义反查 | `hello` → ฮัลโหล |

  反查会把释义按 `；，、／` 切成义项分别匹配（所以「哥哥/姐姐」拆成两个都能查到），顺序是「义项完全相同 → 以它开头 → 包含它」，每档里常用词优先。初学者常打的口语说法（`谢谢`/`对不起`/`好看`…）由 `web/dict/synonyms.json` 映射到词库里的书面写法（`感谢`/`道歉`/`漂亮`），只影响查词、不改卡片上显示的释义。

  词库 2.3MB，平时不加载，第一次查词时才取；取不到就只保留字母/元音搜索。`k` / `kh` 这种短的拉丁串只查字母和注音（那是注音，不是单词）。

> **beta3.1 的 bug 修复**：`สระ อา` 的 `า` 原先被放在元音「前段」，拼出来的 `มา้`（马）、`ก้า` 这类全是错序（`า` 跑到声调符号前面了）。泰文里 `า` 是 spacing 元音，码点上必须排在声调符号之后（`ม้า` = ม + ้ + า）。这条影响很大：所有带调的 อา 音节字形都是错的，**155 个音节拼写（含 35 个常用词）在「常用词」档里根本抽不到**——修复前这 155 个在辞典里的命中数是 0。另外一并修掉了：假簇（ทร）注音漏了尾辅音去重（`ทราย` 拼成 `saii`）、单文件版首屏误报「词库没加载出来」、引导第 7 步跳过会卡在固定模式、长按一个字后一秒内点另一个字块失效、固定模式下换字体/主题后「常用词」又能点了、`全不选` 刷新后丢失、「只选元音」等个别路径字号缩放残留、声调提示指向一个不存在的开关、脏 localStorage 渲染成乱码卡片、词库加载失败时仍承诺「一定是真词」。

- **随机拼装**：前引元音 → 首辅音（可带辅音簇）→ 元音前段 → 声调符号 → 元音后段 → 尾辅音，严格遵守泰文码点顺序。
- **两种模式**（点「随机组合」按钮右半边的 ⇄ 切换）
  - 随机模式：每次随机出一个音节，适合自测。
  - 固定模式：自己在词表里点一个辅音、一个元音，卡片立刻拼给你看，适合跟读跟练。也可以只点辅音（显示 `กอ` 这类字母本身读法）或只点元音（显示 `อา` 这类单元音写法）。
- **组合范围三档**（在模式按钮正下方，两种模式都看得到）

  | 档位 | 随机组合怎么拼 | 固定模式 |
  | --- | --- | --- |
  | 任意 | 不做规则检查，可能拼出泰语里不存在的组合 | 只选元音时不补 `อ` |
  | 按规则（默认） | 按泰语拼写规则拼，禁用这个组合用不上的声调 | 单选元/辅音时用 `อ` 补位 |
  | 常用词 | 只从常用词里取，抽到的一定是真实存在的词 | 等同于「按规则」 |

  做成一条三档而不是两个开关，是为了不出现「不检查规则却只出常用词」这种自相矛盾的状态。
- **词表勾选**：44 个辅音按中类 / 高类 / 低类分组，默认全开（只有 ฃ ฅ 两个废弃字母默认关）；元音按课本的 **สระ 32 รูป** 分组——单元音 18 / 复合元音 6 / 超额元音 8，另列 3 个拼写变体（`ั` `เ-ิ` `เ-็`；第 4 个变体「不写元音符号」没有字形，不在词表里，由「选项 → 允许无元音符号的闭音节」控制）。两组各有一键「全选 / 全不选」。
- **模式切换有衔接动画**：点 ⇄ 时卡片内容先滑出去、换好内容再从另一侧滑进来（切到固定模式往左、切回随机往右），模式按钮同时收一下。只动透明度和位移，卡片每行是定高的，所以下面的按钮不会跟着跳；系统设了「减弱动态效果」时直接跳过动画。连点 ⇄ 也能正确来回切，不会丢操作。
- **辞典**：侧栏的常用词牌组，一次只摆几个词，点「换一批」接着翻，点某个词就把它放到主卡片上放大显示。详见下面「辞典与数据来源」。
- **卡片标注**：真词标「真词」并给出释义，不是真词标「无义」；释义还会带上 `常用`（词表最基础那一档）、`虚词`（没有实义、只起语法或语气作用，如 ครับ ค่ะ นะ）、`英文`（中文词表没收录，退回英文释义）、`无释义`（确实存在但两套词表都没给释义）。
- **首屏默认显示 `สวัสดี`**：打开页面不是一张空卡片。
- **新手引导 + 更新内容**：第一次打开会走一遍 5 步引导（卡片、随机/固定、声调、词表、辞典，每步一句话）；走完再弹一次当版更新内容。两个都能从页脚随时重看。
- **悬停 / 长按看注释**：鼠标停在词表的字块上（或键盘聚焦）会弹出放大卡片，合并显示字形、类别、罗马注音、长短音、例词（辅音用传统例词如 `ก ไก่（鸡）`，元音用课本例词）。手机上**长按**同样能弹，长按不会误触发选中；点到别处或滚动自动收起。
- **元音充当声母**：可开启，让 `ฤ ฤๅ ฦ ฦๅ` 自己成音节（`ฤดู`、`ฤษี` 类型）。
- **复合声母按真实读音处理**：前引辅音（`หมา = ma`、`หรู = ru`）、假簇（`จริง = jing`、`ทราย = sai`、`ศรี = si`）、真簇（`ปลา = pla`、`ความ = khwam`）分别处理，卡片上会标出「前引 ห 不发音」「ทร 整体读 s」这类说明。
- **声调自选**：无音调 + ่ ้ ๊ ๋，点一下即时换，卡片立刻重排；这个组合用不上的声调会变灰，并说明原因。
- **实际读第几调**：卡片上的「声调」那一行回答的是**读出来是第几调**，不是写了什么符号——低辅音 + 长元音 + ้（比如 `รู้`）写的是 โท，读出来是第 4 调 ตรี。规则按教材的「无尾音 / 有尾音」两段实现：辅音类别（中/高/低，前引 ห 与真簇都按第一个字母算）× 音节死活（คำเป็น / คำตาย）× 写的声调符号。
- **词的特殊读法**：拼写和读音不一样的词（`ไทย` 读 `ไท`、`สัตว์` 读 `สัด`、`ใหญ่` 读 `ไหฺย่`）会多显示一行 `读音`。数据来自维基词典的发音区（Phonemic 字段），词典里 11078 条有这一项。
- **规则检查可关**：`๊` / `๋` 只用于中类辅音；`เ-็` 类元音不写声调符号。切到「任意」档就可以随便试。
- **选项随模式变化**：固定模式下「允许辅音簇 / 允许尾辅音 / 允许元音充当声母 / 允许无元音符号的闭音节 / 随机后自动朗读」会变灰、点不动（只影响随机生成）。
- **字体可选**：标准体（Sarabun，泰国政府文书标准字体）/ 印刷衬线（Noto Serif Thai）。两种都打包进仓库，中文界面字也按用字切好子集放进来，所以**不依赖机器上装了什么字体**，换台电脑字形一样。
- **暗色模式**：跟随系统 / 浅色 / 深色三选一，同样会记住。
- **自适应排版**：窄屏单列、宽屏自动变两栏（卡片在左、词表在右），窗口变矮时卡片和字号跟着收。
- **换音节时页面不跳**：卡片里音节、释义、分解、说明每一行都按最高情况定高，长音节按字数缩字形但不改行高——所以连点随机组合时，下面的声调和按钮纹丝不动。
- **发音**：真词（卡片上标「真词」的词、辞典里的词）用**内置发音**——5,393 条 AI 合成音频，按泰语拼读规则做过声调曲线校正（低辅音标 ่ 读第 3 调、前引 ห 按高辅音算、ทร 读 s 这些都按实际读出来的调校正），任何设备都能出声，安卓也不需要泰语语音包。
  随机生成的无义音节没有内置音频，自动回退到系统泰语语音（Windows 11 的 `Microsoft Niwat Online`、macOS/iPhone 的 `Kanya`），这时才需要装语音包；没装时页脚会提示，鼠标停上去能看到各平台的安装路径。
- **快捷键**：空格随机组合，Enter 朗读。
- **选择记忆**：词表与选项存在 localStorage，下次打开还在。

## 快速开始

### 跑起来

```bash
python3 -m http.server 8901 --directory web
# 然后打开 http://127.0.0.1:8901
```

也可以直接双击 `web/index.html`（页面用普通 `<script>` 加载，不需要打包器，直接打开也能跑）。
注意：直接双击打开时，辞典数据要联网取；断网查词请用下面的单文件版。

### 自测

```bash
node --test web/      # 规则引擎 / 选项全矩阵 / 教学页 / 搜索 / 辞典抽测，全过才算过
```

> **要穷举测试的话先清 localStorage**：页面会把模式、组合范围、词表勾选、字体、外观、是否看过引导都记下来，不清的话结果会依赖上一轮的状态（比如上一轮留在固定模式，这一轮点「常用词」本来就没反应——那一档在固定模式是灰的）。在控制台执行 `localStorage.clear()` 再刷新即可。

`web/combinations.test.mjs` 会把随机模式的 **48 种选项搭配**（组合范围 × 允许辅音簇 × 允许尾辅音 × 允许元音充当声母 × 允许无元音符号）各跑 200 次，固定模式把 **44 个辅音单选 / 35 个元音单选 / 44×35 个辅音元音搭配 × 是否检查规则** 全部跑一遍。

### 打包成单文件发给别人

```bash
node web/build-standalone.mjs      # 生成 dist/泰语组合练习.html 与 dist/泰语教学.html
```

产物把 CSS、JS、字体、辞典数据全部内联进 HTML（约 4.8MB），**零外部引用**——发过去双击就能用，不需要联网、不需要装泰文字体，也不受 `file://` 跨域限制影响，断网也能查词。改动界面或辞典后重新跑一次即可（脚本会自检有没有残留外部引用，有就报错退出）。

## 拼写规则与实现要点

- 泰文的前引元音（เ แ โ ใ ไ）在 Unicode 里排在辅音**前面**，但显示在**左半边**，所以拼接顺序固定为
  `前引元音 → 首辅音(+辅音簇) → 元音前段 → 声调符号 → 元音后段 → 尾辅音`，顺序写错就会渲染错位或叠字。
- 声调符号的位置在**元音后段之前**：`น้ำ` = น+้+ำ、`โต๊ะ` = โ+ต+๊+ะ、`เปล่า` = เ+ป+ล+่+า、`เพื่อน` = เ+พ+ื+่+อ+น。所以元音被拆成「前段 / 后段」两截。
- `ัว` 在带尾辅音时会省掉 `ั`：`ตัว` → `สวย`、`ช่วง`。
- 尾辅音共 37 个字母（只有 ฃ ฅ ผ ฝ ห อ ฮ 不能作尾辅音），按 แม่กก/กด/กบ/กน/กง/กม/เกย/เกอว 归类。
- 复合声母分三类：真簇（`กร กล คร คล ตร ปร ปล พร พล ฟร กว ขว คว`，两个字母都读）、前引辅音（`ห` 打头的 `หง หญ หน หม หย หร หล หว`，`ห` 不发音）、假簇（`จร` / `ศร` 第二个字母不发音，`ทร` 整体读 s）。
- 元音本来就以某个音结尾时，尾辅音不重复写：`ไทย = thai` 而不是 `thaiy`；`ย` 作尾辅音时罗马注音用 `i`（`สาย = sai`），`ว` 用 `o`（`แมว = maeo`）。
- 引擎**不**判断组合是不是真实存在的泰语词，只保证码点顺序合法、不叠字、约束成立。「是不是真词」交给辞典数据去回答。
- 卡片注音只有**罗马注音**一种（拉丁字母拼读，`มา = ma`），**不含声调**，只作提示；长短音在元音名称里标了（`สระ อา` 长 / `สระ อะ` 短）。引擎里还留着国际音标（`romanize(parts, 'ipa')`）与各处的 `ipa` 字段，测试仍在拿它跟课本比对，界面上已经不显示了。
- 44 个辅音的传统例词（`ก ไก่`、`ข ไข่` …）写在 `rules.js` 的 `CONSONANT_EXAMPLES` 里，测试会检查 44 个字母都有例词与中文释义。

## 没收录的东西

- `ฃ` `ฅ`：已废弃，仅保留在词表里供手动开启。
- 单独用 `็` 代替 `ะ` 的写法（`ก็`、`จ็` 这类）没有建模，只有 `เ-็`。
- `อักษรควบไม่แท้` 只收了 `จร` `ศร` `ทร` 三个常见组合，其它（如 `สร`、`ซร`）没收录；`หร` 等前引组合也只能从「辅音簇」里生成，不能单独指定。
- `ฤ ฤๅ ฦ ฦๅ` 按「跟在辅音后面的元音」收录（`กฤ`、`พฤกษ์`）；自己成音节（`ฤดู`）要打开「元音充当声母」。
- 复合元音 `เ-ือะ`、`ฦ`、`ฦๅ` 课本的例词栏是空的，卡片里也就没有例词。

## 已知限制

- `ั`（a_short）、`เ-ิ`、`เ-็` 这三个元音**必须带尾辅音**，而固定模式没有尾辅音可选——这三条在固定模式下会拼出不完整音节，卡片上会提示「换一个元音」。
- 全库 27522 条真词里，有 626 条两套词表都没给释义，卡片上标「真词 无释义」。
- 英文兜底释义来自维基词典，可能有错译或挑了偏义项；中文释义来自第三方词表，质量取决于原表。这些是数据问题，靠人工校对解决。
- 安卓系统的 TTS 语音包通常不带泰语，所以安卓上大概率没声音（页脚有说明）。发音方案的改进单独排期。
