泰语组合练习 · 使用说明
（这是一个网页文件，双击就能打开，不需要联网、不需要安装任何东西）


一、在电脑上打开（推荐，最省事）

  1. 微信里收到「泰语组合练习.html」后，不要直接在微信里点开
  2. 点文件旁边的「另存为」，存到桌面
  3. 在桌面上双击这个文件，就会用浏览器打开
       Windows：如果弹出"你要如何打开这个文件？"，选 Chrome 或 Edge
       Mac：双击默认用 Safari 打开
  4. 看到标题「泰语组合练习」和一张大卡片，就说明打开成功了
     第一次打开会有个简短的新手引导，走完之后会弹一次更新内容说明

  另外还有一个「泰语教学.html」，是从头讲拼读的：44 个辅音、32 个元音、
  尾辅音、声调规则各有一张表，每个字母都配了发音讲解。
  两个文件放在同一个文件夹里，页面右上角可以互相跳转；
  只发「泰语组合练习.html」也能正常用，只是那个跳转链接点不开。


二、在手机上打开

  安卓：微信里点开文件 → 右上角「…」→「用其他应用打开」→ 选浏览器

  iPhone：微信里点开文件 → 右上角「…」→「用其他应用打开」→「存储到"文件"」
         → 打开手机上的「文件」App，找到这个 html 文件点开
         ⚠️ 手机上用「文件」App 或微信直接预览，页面里的脚本不会执行，
            你会只看到标题和几个空框，页面上会有一段说明文字告诉你这一点。
            那不是文件坏了，**这种情况请改用电脑打开**。


三、怎么用

  · 想先补一下基础，点右上角「拼读教学 →」，里面把辅音、元音、尾辅音、
    声调规则从头讲了一遍，每个字母都写了发音讲解
  · 点「随机组合」出一个音节；点「播放发音」读出来
  · 两种模式，点「随机组合」按钮右半边的 ⇄ 切换：
      随机模式：点「随机组合」，每次换一个新音节，适合自测
      固定模式：自己在词表里点字母，卡片立刻拼给你看，适合跟读跟练
        - 只点一个辅音（不点元音）→ 显示 กอ 这样的字母本身读法（单辅音）
        - 只点一个元音（不点辅音）→ 显示 อา 这样的单元音写法（前面的 อ 是载体）
        - 再点一次已经选中的字母就是取消
  · 模式按钮正下方是「组合范围」，从宽到严三档：
      任意    不做规则检查，可能拼出泰语里不存在的组合
      按规则  按泰语拼写规则拼，用不上的声调会变灰（默认这一档）
      常用词  只从常用词里取，每次出来的都是真实存在的词
    固定模式下「常用词」用不上（会变灰）；另外「按规则」还决定
    单选的辅音/元音要不要自动补一个 อ 当载体
  · 大字下面的小字是注音（罗马注音，不含声调，只作提示）
  · 卡片上还会标出这个拼写是什么：
      真词    泰语里真实存在的词，后面跟着意思
      无义    泰语里没有这个拼写（大多数组合都是这种，这是故意的）
      常用    属于词表里最基础的那一档（约 2000 条）
      虚词    没有实义、只起语法或语气作用（ครับ ค่ะ นะ 这类），不用记"意思"
      英文    中文词表没收录这个词，退回英文释义
  · 声调：点「无 ่ ้ ๊ ๋」中的任意一个，卡片上的写法会立刻跟着变
    （灰色的声调表示这个组合用不上，是泰语规则决定的）
  · 词表：想练哪几个字母就勾哪几个，右边有「全选 / 全不选」
    （固定模式下没有「全选 / 全不选」——直接点字母挑选就行）
  · 辞典：展开侧栏的「辞典」，一次会摆出几个常用词，
    点「换一批」接着翻；点某一个词，它就会显示在上面的大卡片上（带注音和意思）
  · 「允许无元音符号的闭音节（กบ = kop）」默认关闭。打开后随机组合会出现
    กบ、นก、ต้ม 这类不写元音符号的闭音节（读 /o/，真实文本里非常常见）。
    这种写法本身没有字形，所以不放在元音词表里，改成这个开关控制。
  · 上面这几项只对随机模式生效，切到固定模式会变灰、点不动；
    字体、外观、组合范围两种模式都能用
  · 鼠标停在任意字母上（手机上长按）会弹出放大卡片，
    能看到这个字母的名称、读音、传统例词（如 ก ไก่）和中文意思
  · 页脚有「新手引导」和「更新内容」两个入口，随时可以重看
  · 组合出来的音节大多没有实际词义，这是故意的：
    不背单词，只练"看到拼写就能读出来"这条肌肉记忆
    想直接练真词，把「组合范围」切到「常用词」就行

  快捷键：空格 = 随机组合，回车 = 播放发音


四、常见问题

  · 打开后只有一堆英文字母和符号 → 是被当成文本打开了，
    请改用浏览器打开（右键 → 打开方式 → Chrome / Edge / Safari）
  · 手机上打开只有标题、没有内容，或者提示「这个页面没能运行起来」
    → 你用的是不支持脚本的预览器，请改用电脑打开
  · 点「播放发音」没有声音 → 这台设备没有装泰语语音包，
    其它功能不受影响，跟着注音自己读也可以
    ⚠️ 安卓手机目前基本都用不了发音：安卓系统的 TTS 语音包里通常
       没有泰语，装不了就没声音。这个会在后续版本里解决。
    （Windows 11 自带泰语语音「Microsoft Niwat Online」，
       Mac 自带「Kanya」；发音就是用系统里这个语音读的）
    如果确实没有，可以自己装一个：
      Windows：设置 → 时间和语言 → 语言和区域 → 添加泰语 → 勾选"语音"
      Mac：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 下载泰语
      iPhone：设置 → 辅助功能 → 朗读内容 → 声音 → 泰语
  · 每次换音节时，下面的按钮会上下跳吗？
    → 不会。卡片的每一行都按最高情况占好位置了（2.0.0 还修掉了「随机 / 固定
      模式切换时整页上下跳 5px」那个小毛病）。
      如果你看到还在跳，多半是浏览器缓存着旧版本，下拉刷新一次即可。
