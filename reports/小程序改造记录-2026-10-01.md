# 小程序改造记录（2026-10-01）

## 起点

`miniprogram/` 已有工程骨架：三个 tab（练习 / 教学 / 词汇）、可用的练习页、
教学页与词汇页占位；`rules.js` / 教学数据 / 发音清单已由 `tools/sync-miniprogram.mjs` 同步。

本轮目标：把教学页和词汇页做出来，并把词库（2.3MB）与 5,393 条音频接到云存储上，
整体做到「能在开发者工具里跑、能在真机上过一遍」的 MVP。

## 做了什么

### 1. 数据链路（云存储，免域名备案）

- `tools/sync-miniprogram.mjs` 增加产物 `dist/miniprogram-dict.json`
  （27,525 条 / 2.2MB，含 `synonyms`，供云存储按需下载）。
- 新增 `miniprogram/config.js`：**唯一要手填的地方**（云环境 ID、词库 fileID、发音包 fileID、两个版本号）；
  删掉原来的 `core/audio-cloud.js`（配置收口到一处）。
- 新增 `miniprogram/utils/dict.js`：云存储下载 → 写 `USER_DATA_PATH` 缓存 → 之后离线可用；
  多个页面同时调用只会下载一次；失败时静默降级（教学页仍能按字母 / 讲解搜索）。
- 新增 `miniprogram/core/dict-search.js`：从 `web/dict.js` 抽出的纯查询逻辑
  （泰文前缀 / 中文 / 英文反查、同义词、换一批），Node 里可直接测。
- 重写 `miniprogram/utils/audio.js`：包内前 20 条试听 → 云端发音包（约 28MB）下载解压到
  版本化目录（`audio-pack-vN`），旧版本目录自动清理；下载前由页面弹一次确认。

### 2. 教学页（`pages/tutorial/`）

- 新增 `utils/tutorial-content.js`：四张表（44 辅音 / 32 元音 / 8 组尾辅音 / 5 个声调 + 规则表）
  全部从 `core/rules.js` 与 `core/tutorial-data.js` 现取，每行登记搜索索引（`r1…r93`）。
- 页面：吸顶搜索 + 目录、严格搜索三档退让、点结果滚到对应行并高亮、
  搜泰文 / 中文会补一段词典结果、点词经 `utils/nav.js` 跳练习页看卡片。
- 尾辅音标签、声调规则表口径与网页版一致；讲解漏项由测试兜底。

### 3. 词汇页（`pages/dict/`）

- 常用词「换一批」（每次 20 条）、泰文前缀 / 中文 / 英文释义反查（最多 50 条）、
  词条详情（罗马注音 / 释义 / 词性 / 读音）、播放发音、一键去练习卡片。
- 词库第一次进页面先问一次（约 2.3MB，省流量），同意后记在本机，之后自动加载。
- 底部标了数据来源与「发音由 AI 合成」（合规用）。

### 4. 练习页补齐

- 支持从教学页 / 词汇页带词跳转（tabBar 不能带参数，走 `utils/nav.js` 的 storage 中转）。
- 词库回退：词不在 5,393 条发音清单里时，按需取词库补罗马注音 / 释义 / 读音。
- 新增「选项」面板：辅音簇 / 尾辅音 / 元音当声母 / 无元音符号 / 自动朗读。
- 词表勾选、组合范围、选项记在本机（含「全不选」这种空数组，不会被当成没存过）。
- 声调按钮垫 `อ` 底座（组合符号单独写会飘）；自动朗读不主动触发 28MB 下载。

### 5. 全局

- 暗色跟随系统：`app.json`（darkmode + theme.json）、`theme.json`、`app.wxss` 媒体查询，
  配色继续用 Tailwind neutral（与网页版同一套色）。
- `project.config.json` 忽略 `tests/` 与 `README.md`（不打包进小程序）。
- 新增 26 项 Node 自测（`miniprogram/tests/`）。

## 验证

- `node --test web/`：81 项全过（本轮没有改 `web/` 的逻辑）。
- `node --test miniprogram/tests/`：26 项全过
  - `dict-search.test.mjs`：拿 `web/data/dict.js` 真实数据测查询（前缀 / 中文 / 同义词 / 英文 / 空查询）；
  - `dict-loader.test.mjs`：假 wx 环境测「下载 → 缓存 → 第二次不再下载 → 没配置时的报错」；
  - `tutorial-content.test.mjs`：四张表数量、每行都有讲解、索引覆盖、严格搜索回归（`ด` `ไ` `ต` `k`）；
  - `pages-smoke.test.mjs`：三个页面的 `onLoad` 与主要交互（随机 / 声调 / 勾选记忆 / 搜索跳行 / 查词 / 详情 / 去卡片）。
- 所有 `.js` 过 `node --check`；所有 `.json` 可解析；所有 `.wxml` 过 XML 结构检查。
- `tools/sync-miniprogram.mjs` 重跑幂等。

## 还没验证（需要开发者工具 / 真机）

- 云存储真实下载与解压：`wx.cloud.downloadFile` 28MB zip → `unzip` 到 5,393 个文件的实际耗时与失败路径；
- `InnerAudioContext` 播放包内路径 `/assets/audio-demo/*.mp3` 与本机路径；
- 暗色在真机的导航栏 / tabBar 表现（theme.json 已按官方格式写）；
- `wx.pageScrollTo({selector})` 跳行、吸顶搜索栏在低端机上的表现；
- 语音包 28MB 下载在弱网下的体验（现在只有 loading，没有进度条）。

## 有意没做的

- **「我的（弱项统计）」页**：需要先定产品口径（第 4 个 tab 还是替换词汇页；自评方式；统计维度），
  并且要先在练习页加「作答」入口才有数据。本轮先不做。
- **固定模式**（自己点字母拼）：规则引擎已支持，差 UI。
- **字体选择**：小程序不能 `@font-face` 打包 woff2，用系统泰文字体。
- 上传自动化：两个云存储文件目前手动传（README 写了步骤）。

## 下一步（用户操作）

1. `project.config.json` 填自己的 AppID；开发者工具开云开发，把环境 ID 填进 `config.js`。
2. `node tools/sync-miniprogram.mjs && node tools/pack-audio.mjs`。
3. 把 `dist/miniprogram-dict.json` 与 `dist/miniprogram-audio.zip` 上传云存储，fileID 回填 `config.js`。
4. 真机过一遍「发音 / 词库下载 / 暗色 / 跳行」这几条没验证的路径。
5. 并行推进：ICP 备案（7-20 个工作日）、类目「工具 > 信息查询」、隐私保护指引。

## 云开发接通（2026-10-01 晚，实测记录）

用开发者工具自带的 `wechatide` CLI（不是点界面）完成了云存储配置：

```
AppID：wx0b48b0400894a6c8
云环境：cloud1-d3gr01svb48b8f4d5
桶 ID：636c-cloud1-d3gr01svb48b8f4d5-1499344170
上传：dict/dict-v1.json（2,315,398 B）、audio/audio-v1.zip（29,301,931 B）
fileID：cloud://<环境ID>.<桶ID>/<cloudPath>（已回填 miniprogram/config.js）
```

在模拟器里逐项验证通过（用 `automation_*` 系列工具驱动，不是靠肉眼看截图）：

1. 词汇页 `status: ready`；`USER_DATA_PATH/dict-v1.json` 落盘 2,315,398 B（与云端一致）；
2. `wx.cloud.downloadFile` 拉 28MB 发音包约 4.2s；
3. `utils/audio.js` 的 `ensurePack()` 下载 + 解压 2.9s，`audio-pack-v1/` 下 **5,393 个 mp3**，
   `playWord('สวัสดี')` 返回 `pack`（走本地文件，不再联网）；
4. 练习页 `randomize()` 生成 `ช่าง`，分解行/注音/真词标注都正常，`canPlay: true`；
5. 开发者工具 Console 里那条 `[渲染层错误] DOMNodeRemoved` 是 Chromium/基础库自己的噪音（灰度基础库 3.17.3），不是本项目代码。

顺带发现：`wechatide` CLI 还能 `simulator_screenshot` / `automation_*` / `cloud_query_storage`，
以后改完小程序可以直接命令行驱动模拟器自测，不必手动点。

**没做**：体验版上传（`wechatide upload` 要求用户明确说「上传代码/发布体验版」才允许调用）；
ICP 备案、类目、隐私指引仍待办。
