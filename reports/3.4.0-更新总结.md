## 二、行为（web 侧，小程序可参考）

1. **固定模式全组合都能出声**：一个辅音 + 一个元音拼出的合法音节（含只选辅音 `กอ`、只选元音 `อา`），
   播放按钮按 `rules.js` 的 `soundKey` 取 `syl/v1/{key}.mp3`，**按声音去重**——
   `ฎา = ดา`、`ฃอ = ขอ`、`กะ = ก่ะ` 共用一条。声调换一个就换一条文件（五个调分得开）。
2. **拼不完整的组合保持灰**：`ั / เ-ิ / เ-็` 在固定模式下缺尾辅音（卡片提示「换一个元音」），
   不生成音频、播放按钮 disabled——判断条件是 `check(parts)` 为空 + 没有簇 / 尾音。
3. **教学页每行一个小喇叭**：辅音读字母名（`กอ`）、元音读「อ + 元音」；
   直接用 `syl/v1/{key}.mp3`（和固定模式同一批校正版）。**不要**换成自然合成的独立字母包——
   试过，TTS 的句尾会往下滑，用户明确说不要。
4. 播放优先级：卡片文本在单词清单里 → 单词音频；否则能算出声节 key → 音节音频；都没有 → 按钮灰掉。
5. **切回随机模式会重抽一张真词卡**：以前会把固定模式拼的音节（可能没有词义、
   声调那排全灰）原样留在卡上，成了「非法却还选中着」的状态；现在直接按当前档位重抽。
