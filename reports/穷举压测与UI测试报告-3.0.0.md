## 二、穷举与压力测试（Node）

### 1. 随机模式全矩阵

- 48 种搭配（组合范围 3 档 × 允许辅音簇 / 尾辅音 / 元音充当声母 / 无元音符号）各 2000 次；
- 每次断言：`check(parts)` 无结构性问题（未知字符、叠声调符号、码点顺序、尾音合法性、辅音簇合法性…）；strict 档要求 `check()` 完全为空；`describe()` 不抛异常；同一个 parts 拼装结果确定；声调符号不出现在 `า ะ ำ` 之后；
- 结果：96,000 次全部通过，生成吞吐约 **33 万次/秒**。

### 2. 固定模式全量

- 44 个辅音单选 / 35 个元音单选 / 44×35 搭配 ×（按规则 / 任意）全部跑一遍；
- 已知例外按设计放行：`ั`、`เ-ิ`、`เ-็` 在固定模式下缺尾辅音（界面会提示）；「任意」档只选元音时不补 `อ`；
- 结果：3,266 个组合，无非预期错误。

### 3. 畸形输入 fuzz（22 万次）

- 把 `undefined / null / -1 / NaN / 对象 / 数组 / 错误字符` 灌进 parts 的每个字段，跑 `check()` / `romanize()` / `describe()`：**0 次抛异常**（2.0.0 修过的兜底仍然有效）；
- `generate()` 对 `null` 词表会抛 `TypeError`（`Cannot read properties of null`）。**判定：不是用户可达 bug**——界面永远传数组，localStorage 脏数据也会先过白名单；列为加固项，本轮未改。

### 4. 辞典全量体检

- 27,525 条逐条检查：定长 8 位、无重复拼写、词性码合法、中文释义不混泰文、罗马注音不混中泰文、IPA / 实际读音格式正确；
- 629 条两套释义都没有（界面标「无释义」，与文档一致）；2,378 条超过 8 码点（多音节词，属正常）；
- 双向查词：泰文前缀查询每条结果都真的以查询串开头、整词排第一；中文反查 `你好 → สวัสดี`、`谢谢 → ขอบคุณ`、英文 `hello → ฮัลโหล`；`nextBatch()` 200 轮只出常用词；`isWord/isCommon` 与全库逐条一致。

### 5. 声调规则 × 辞典 IPA 反查

- 穷举 UI 可达的单音节写法，取辞典里带维基词典 IPA、只有一个声调组的真词做比对；
- **3,198 个可比对词，34 个不一致（98.94%）**：`เก็ต กราฟ บอส บัส แอป เคส คลาส ชีส …` 全是英语借词（词级读第 4 调，与拼写规则无关）；`คลับ เพจ เฟส` 是同一批借词的数据边缘；`ช่ะ` 是一形多读。**结论：规则本身没有新问题**。

## 五、发现与修复

### 真 bug（已修）：切换「组合范围」后提示不更新

- **现象**：点「任意 / 按规则 / 常用词」，下面那句说明停在上一档。实测序列：点「任意」仍显示「按泰语拼写规则拼…」；点「常用词」会更新（因为顺手加载词库），再切回「按规则 / 任意」又一直显示「只从常用词里取…」。
- **根因**：`applyRangeHint()` 只在 `renderSettings()` 末尾、词库加载完、切模式时调用；三档控件的 `onPick` 里只调了 `flashHint()`（只做淡入动画），没有重算文案。
- **修复**：`web/app.js` 的 range `onPick` 里在 `syncRange()` 之后调用 `applyRangeHint()`（同时覆盖随机/固定两套文案）。
- **验证**：浏览器测试新增两条断言（随机模式三档来回切、固定模式下切「任意/按规则」），29/29 通过；`node --test web/` 81/81。

### 外部模型（千问）结论复核

- 千问记录：「发现叠字问题：1078 个组合被 check() 放过，含 `กก`（声母 + 尾）这类畸形字形」。
- **复核结论：误报。** 泰语允许声母与尾辅音同字（`กก` 本身就是真词「芦苇」；`กาก`、`ก๊อก`、`กัก`、`เกือก` 同理）。用辞典实测：UI 可达音节 182,648 个，其中「首辅音 = 尾辅音」3,941 个，**93 个是真词**；全库首尾同字母的真词 541 个。`rules.js` 的 `check()` 也专门按“角色”而不是按“字符是否重复”判断（注释里写明 `ปลื่ป` 这类不能误判）。
- 千问的 UI 测试用 jsdom 且脚本被截断，没有产出结论；本轮已用真实 Chromium 补完（第三节）。

### 观察项（有意未改）

1. `rules.generate()` 对 `null` 词表抛异常：界面不可达，属 API 加固项；
2. 教学页声调例词用带调号的罗马注音（`kài / tôm`），卡片注音不带调、辞典用 Paiboon（`gài / dtôm`）——三处风格不同但各自成立的展示选择，改动需要产品取舍；
3. `web/dict/.cache/` 有 70MB 构建缓存（`.gitignore` 已忽略，可重下，不影响运行与打包）；
4. 仓库根目录有 `.DS_Store`（macOS 元数据，已忽略）。
